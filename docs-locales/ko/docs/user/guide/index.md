# Web UI 사용

[루트 README](../../../README.md#run)를 통해 Web UI를 시작하면 명령이 URL을 출력합니다. 이 가이드는 해당 서버가 실행된 후부터 시작합니다. `dsh` 프로세스는 호출한 디렉터리를 기본 파일 시스템 위치로 사용하지만, 새 Web UI에는 워크스페이스를 추가하기 전까지 선택된 워크스페이스가 없습니다.

## 모델 설정

**Settings → Models**를 열고 DeepSeek API 키를 입력한 뒤 저장합니다. 서버를 다시 시작하지 않아도 모델 경로를 즉시 사용할 수 있습니다.

[모델 구성 가이드](./providers.md)에서 다른 제공자와 사용자 지정 OpenAI 호환 엔드포인트를 확인할 수 있습니다.

## 워크스페이스 선택

**Choose workspace**를 클릭하고 `dsh`를 시작한 프로젝트 디렉터리를 추가한 다음 선택합니다. 워크스페이스를 선택할 때까지 세션 작성기를 사용할 수 없습니다.

## 작업 실행

세션을 시작하고 다음을 전송합니다.

> 이 리포지토리를 요약하고 주요 패키지를 식별하세요.

에이전트는 워크스페이스 파일을 읽고 편집하며, 명령을 실행하고, 작업을 위임하고, 계획을 유지할 수 있습니다. Web UI는 활성 권한 정책에 따라 승인이 필요한 작업 전에 확인을 요청합니다.
