# Diff triage rules

- **Low**: spelling, a small label, one literal, or one link target; no heading,
  code, structure, protocol, security, or behavior change.
- **Mid**: bounded prose/code/table updates, a new subsection, screenshots, or a
  localized navigation adjustment with a clear review surface.
- **High**: page/catalog addition or removal, module regrouping, VitePress
  behavior, architecture/protocol/security semantics, large structural edits,
  generation changes, locale fallback, or ambiguous pairing.

The classifier is a starting point. Record a Chinese summary and review
recommendation for every material canonical page. Never invent `+0/-0`; omit
line statistics when they were not derived from the frozen diff.
